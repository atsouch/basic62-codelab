# Changelog

## 0.1.0 (2026)

First public prototype of BASIC62 CodeLab and the BASIC62 language, following BASIC62 language specification v0.1. Released under the MIT License.

- BASIC62: a BASIC-inspired language with English and Spanish editions, dynamic typing, functions, classes with inheritance, error handling, tests and DOC blocks.
- 111 built-in functions covering core operations, text, turtle graphics, screen controls, offline web data samples, data tools and charts, a simulated network and security.
- CodeLab: a browser environment with editor, stage, step-by-step debugger and visualizations (variables, memory, trace table, class diagram, flowchart).
- Tests tab with coverage and test plan, docs and credits tools, simulated git history, Python translation and download, files and reference tabs.
- Ten example programs and built-in sample datasets.
- 149 engine tests and a browser smoke test.
